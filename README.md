# Cooking

A working cookbook for repeatable food that tastes good. Recipes start as experiments; measurements and methods become the standard only after tasting and adjustment.

- `recipes/` — recipes and current working versions
- `experiments/` — tasting notes and changes to try
- `prep/` — batch preparation and storage systems

Record actual ingredients, weights, yields, cooking temperatures, and changes when known. Do not treat provisional quantities as tested results. Nutrition estimates depend on ingredients and serving size.
